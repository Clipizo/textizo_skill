# Textizo preset kit

This folder lets an AI agent make presets for **Textizo**, a text animation node for DaVinci Resolve (Fusion page).

When the user asks for a Textizo preset, a text animation, a title look or changes to one, **read `SKILL.md` and follow it**. It points you to `Textizo AI Guide.md`, the full reference.

Ground rules:

- Ask the user where to save presets before writing anywhere outside this folder.
- Put new work in `my-presets/`. Leave the kit files unchanged unless the user asks: `presets/`, `specs/`, `reference/`, `tools/`, the guide, `SKILL.md`.
- Do not delete or overwrite the user's files without asking.
